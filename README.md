# REVEX CODE

Локальний AI-кодер для Windows: чат + редактор коду (Monaco) + локальні моделі через **Ollama**. Без API-ключів, історія зберігається на вашому ПК.

## Швидкий старт

**Готовий exe через GitHub (без нічого на вашому ПК)**
1. Створіть репозиторій і завантажте в нього **вміст** цієї папки (щоб `package.json` лежав у корені; папка `.github` обов'язкова).
2. Вкладка **Actions → Build REVEX CODE (Windows) → Run workflow** (або просто зробіть push у `main`).
3. Через кілька хвилин у запуску з'являться артефакти `REVEX-CODE-windows`: `REVEX-CODE-Setup-*.exe` (інсталятор) і `REVEX-CODE-Portable-*.exe`.
4. Для релізу: створіть тег `v1.0.0` — exe автоматично прикріпляться до GitHub Release.

**Запуск із вихідників** (потрібен Node.js 20+):
```
npm install
npm start
```
Збірка exe локально: `npm run dist` (результат у `dist/`). Перевірка логіки: `npm test`.

## Перший запуск
Майстер налаштування перевіряє обладнання (RAM, VRAM, диск), рушій Ollama і пропонує сумісну модель. Нічого не завантажується без вашого підтвердження. Якщо Ollama немає — кнопка «Встановити Ollama» завантажує офіційний інсталятор з ollama.com і запускає його (лише Windows).

## Можливості
- **Чат зі стрімінгом**, кнопки «Зупинити», «Продовжити», «Повторити»; швидкість у токенах/с і час до першого токена показуються за даними Ollama.
- **Моделі**: каталог (Qwen2.5-Coder, Qwen3-Coder 30B, DeepSeek Coder / V2, Llama 3.2, gpt-oss 120B та vision-моделі) з оцінкою сумісності (GPU / GPU+CPU / CPU / не підходить), вимог RAM/VRAM і місця на диску. Завантаження з прогресом, швидкістю, паузою (продовження з місця зупинки) і скасуванням. Модель 120B ніколи не рекомендується й не качається автоматично.
- **Режим «Авто»**: проста задача → найшвидша з встановлених, складна → найпотужніша, що тягне ваше обладнання; якщо є фото — vision-модель.
- **Хмарні моделі** (OpenAI/Anthropic/Google) показані окремим статусом «не підключено» — вони потребують API-ключа і в цій версії не імітуються.
- **Контекст проєкту (RAG)**: індексація папки (BM25 по фрагментах), короткі резюме файлів, граф залежностей (import/require/include), автоматичний добір релевантних фрагментів у межах бюджету токенів. Контекст у інтерфейсі показується **за реальним значенням моделі** (`context_length` з Ollama): «1M» з'являється лише для моделей, які його справді підтримують.
- **Фото**: PNG/JPG/JPEG/WEBP — кнопка «+», перетягування, Ctrl+V. Vision-модель бачить зображення напряму, для інших працює OCR (tesseract.js, eng+ukr+rus; мовні дані завантажуються при першому використанні). Відео не підтримується.
- **Редактор**: Monaco (підсвічування, номери рядків, автодоповнення, пошук/заміна Ctrl+F / Ctrl+H, кілька вкладок). Кнопка «Застосувати» біля блоку коду з відповіді показує **diff** → «Прийняти» / «Відхилити»; прийняту зміну можна скасувати Ctrl+Z, збереження — Ctrl+S. Контекстне меню: пояснити / виправити / рефакторинг / тести.
- **Запуск коду** (▶) — тільки за явним підтвердженням і в **тимчасовій копії** проєкту (py, js, ts, lua, c, cpp; потрібні відповідні інтерпретатори/компілятори в PATH, для js використовується вбудований Node). Таймаут 60 с, змінні середовища з KEY/TOKEN/SECRET/PASSWORD не передаються.
- **Кеш відповідей** (для запитів із температурою ≤ 0.3), локальна історія чатів, мови інтерфейсу: українська та English.

## Структура
```
src/main/      main.js (IPC), ollama.js, models.js, indexer.js, hardware.js, ocr.js, runner.js, store.js, cache.js
src/renderer/  index.html, styles.css, app.js, editor.js, i18n.js, util.js
src/shared/    blocks.js (розбір код-блоків відповіді)
tests/         run.js, ollama-mock.js
.github/workflows/build.yml
```
Дані користувача: `%APPDATA%/revex-code` (settings.json, chats/, cache.json).

## Чесні обмеження
- Запуск у тимчасовій копії — це ізоляція файлів проєкту, а **не віртуальна машина**: код виконується з правами вашого користувача. Запускайте лише те, що розумієте.
- Швидкість залежить від вашого заліза та моделі; великий контекст (64K+) потребує багато RAM/VRAM.
- VRAM визначається лише для NVIDIA (`nvidia-smi`); для AMD/Intel сумісність оцінюється консервативно за RAM.
- Розміри моделей у каталозі наближені; точні числа показує Ollama після завантаження.
